Exercice 02 - XML vers (X)HTML

  • fichier à transformer : 02/will_AD95_0048.xml
  • feuille de transformation : 02/tei2html.xsl

Macro-structure HTML

  • Définissez une première règle pour le nœud document afin d’appliquer les modèles aux nœuds descendants.
  • Créez une règle qui transforme l’élément <TEI/> en un élément HTML <html/> et appliquez les modèles.
  • Ajoutez une règle pour l’élément <teiHeader/> afin qu’il soit transformé en un élément HTML <head/> contenant :
    • un élément HTML <meta charset="utf-8"/>
    • un élément HTML <title/> dont la valeur textuelle correspond au titre principal du document TEI.
  • Créez une règle qui transforme l’élément TEI <body/> en un élément HTML <body/>, et appliquer les modèles aux nœuds descendants.
  • Ajoutez une règles pour transformer les éléments TEI <div/> en élément HTML <section/>. L’attribut @type doit devenir une classe. N’oubliez pas d’appliquer les templates.
  • Établissez des templates pour transformer les éléments suivants en paragraphes HTML <p/>:
    • head
    • p
    • dateline
    • signed

    Pour les éléments <head/> et <dateline/>, ajoutez un attribut @class dont la valeur correspond à celle de l’attribut TEI @rend.

Contenus

  • Créez une règle qui transforme les éléments <lb/> en éléments HTML <br/>.
  • Ajoutez une règle afin que seuls les éléments <corr/> et <expan/> soient instanciés dans les éléments <choice/>
  • Créez une règle pour supprimer les nœuds <del/> et <add type='testatorComment'/> en sortie
  • Créez une règle afin d’instancier les éléments <supplied/> entre crochets droits []
  • Ajoutez une règle pour les éléments <pb/> et créez une variable pour numéroter les changements de page.
    En sortie, placez le numéro de page entre crochets [].
