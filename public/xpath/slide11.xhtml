Les étapes

/child::body/child::div

  • Le point de départ est la racine du document : / ;
  • chaque étape est séparée de la précédente par l’opérateur / ;
  • une étape correspond à axe::test :
    • l’axe indique la direction dans laquelle on se déplace (nœud fils = child),
    • le test correspond au nœud que l’on recherche (nom du nœud).
